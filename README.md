🎮 태초마을 LoL 내전 관리 디스코드 봇 (TAECHO Bot)

구글 스프레드시트(Google Sheets)와 연동하여 리그 오브 레전드 내전 전적 관리, 유저 등록, 승률 순위 조회 등을 자동으로 처리하는 디스코드 봇 프로젝트입니다.

---

## 📌 주요 기능

- **📊 실시간 내전 승률 및 순위 조회**
  - 구글 시트의 내전 순위 데이터를 파싱하여 디스코드 임베드(Embed) 형태로 Top 5 승률/전적 제공
  - 유저별 디스코드 ID 기반 전적, 티어, 총점 조회
- **📝 디스코드 UI 기반 유저 등록 시스템**
  - 디스코드 드롭다운(Select Menu) 및 모달(Modal) 팝업창을 활용한 직관적인 유저 정보 입력
  - 약 30여 개의 대량 데이터(이름, 롤 ID, 포지션, 최고 티어, 모스트 챔피언 등)를 구글 시트 양식에 맞춰 자동 정렬 및 저장
- **⚡ 메모리 캐싱(Caching)을 통한 API 최적화**
  - Google Sheets API 사용량 제한(Rate Limit)을 방지하고 응답 속도를 극대화하기 위해 시트별 메모리 캐시 알고리즘 적용
  - 데이터 변경(등록/수정) 발생 시 캐시 자동 초기화

---

## 🛠 기술 스택

- **Language:** Python 3.10+
- **Library:** `discord.py` (v2.0+), `gspread`, `google-auth`
- **Database / Storage:** Google Sheets API v4
